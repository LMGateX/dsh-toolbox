# DSH Toolbox 0.1.0

First unified release targeting DSH 0.2.2-alpha.3 and Node >=24.9.0.

## Included
- One combined plugin card with four independently configurable modules.
- Four real same-source single-module distributions: context, retry, chime, goal-wait.
- Preserved native-policy compaction and context options, official-retry classification, lifecycle-safe browser chimes, and conventional goal waiting alongside the official driver.
- Current-profile legacy discovery/import, persistent disable handover, protected journal/backups, inspect/dry-run/retry/selective recovery.
- Truthful active/pending/conflict/restart-required state; legacy chime requires a fresh host and full page before taking over audio.

## Install
Choose the combined tarball OR distinct split tarballs, not overlapping owners. Install through DSH Plugin Manager from the attached GitHub tarball URLs. Verify [SHA256SUMS](https://github.com/LMGateX/dsh-toolbox/releases/download/v0.1.0/SHA256SUMS). This release does not publish to npm.

## Migration safety
Only known audited legacy sources are imported automatically. Ambiguous/dynamic/read-only/unsupported ownership fails closed per capability. Old packages/configuration are retained. No forced restart, no package-uninstall side effects, no experimental startup-driver replacement. See the [README](https://github.com/LMGateX/dsh-toolbox/blob/v0.1.0/README.md) and [migration contract](https://github.com/LMGateX/dsh-toolbox/blob/v0.1.0/docs/MIGRATION.md) for recovery and handover details.
