Preserve: top-level classification by origin=subagent (parentId alone is insufficient); owned running/stopping jobs and working subagents hold completion; active goal holds normal completion but not failed-turn settlement; blocked rings immediately once; baseline idle is silent; new question/plan-review/approval keys ring once, clears are token-fenced; error is distinct. Attach jobs/uiSession/remote through late-bound optional scopes, never one-shot context lookup. Retain all 18 fields/defaults, four reason sounds and question/error switches; duration 0 means one clip, volume defaults 0.8, debounce 1500 ms, quiet-short 600 ms, minimum gesture ring 3000 ms. Keep preview's staged sound but live accepted quiet/volume settings. Keep sidebar footer order 50, narrow/wide moon/bell display, revision-fenced accepted-value rest toggle; overlay order 100, seven placements, modal mask, accents/title, explicit stop bypassing minimum guard. ## Native client requirements

Each package has its own patch row, ./client export and one classic-script __ModuleLoader__.load factory whose id equals packageName. Return a Module-tagged namespace exposing inject/apply; use platform React through require inside factory. No ESM syntax or shared global declarations in emitted combo-safe scripts. Local modules may be bundled; do not bundle a second React or Cordis. Sources: [existing namespace](</home/dev/dev/dsh-session-chime/client/main.ts#L2035-L2040>), [IIFE assembly](</home/dev/dev/dsh-session-chime/scripts/build-client.mjs#L4-L10>), [host export resolution](</home/dev/.local/lib/node_modules/@deepseek-ai/dsh/node_modules/@deepseek-ai/dsh-client-modules/lib/index.js#L783-L801>).

Manifest dsh.client.inject is a string array of package ids for arrival ordering; factory inject is a flat string array of service names. Do not conflate them or use {required,optional}. Outer settings only need slots/configForms; chime sessions and optional siblings should be nested so missing providers do not park unrelated sections. Sources: [manifest validation](</home/dev/.local/lib/node_modules/@deepseek-ai/dsh/node_modules/@deepseek-ai/dsh-client-modules/lib/index.js#L78-L99>), [package arrival](</home/dev/.local/lib/node_modules/@deepseek-ai/dsh/node_modules/@deepseek-ai/dsh-client-modules/lib/client.js#L785-L795>), [flat service injection bug](</home/dev/dev/dsh-session-chime/client/main.ts#L1628-L1638>).

Native Config must be Schemastery with toJSON; namespace appears only for an active row with volatile fields. Preserve volatile leaves, avoid volatile ancestor plus volatile descendants. Context watermark fields remain nonvolatile/YAML-only unless specifically amended. Sources: [eligibility](</home/dev/.local/lib/node_modules/@deepseek-ai/dsh/node_modules/@deepseek-ai/dsh-settings/lib/index.js#L413-L419>), [writes/schema](</home/dev/.local/lib/node_modules/@deepseek-ai/dsh/node_modules/@deepseek-ai/dsh-settings/lib/index.js#L501-L540>), [nested volatile warning](</home/dev/dev/dsh-session-chime/src/config.ts#L4-L15>), [context policy](</home/dev/dev/dsh-tool-compact-context/src/config.ts#L40-L68>).

Package slot plugins.bundle.config key is packageName; it receives only view, so inject/use shared root configForms.get(rowId) explicitly. Retry already adapts native page form to stable getSnapshot/subscribe/mutate. ## Proposed interfaces and topology

Build contract: createToolboxClient({rowId,packageName,moduleIds}, optionalChimeAdapter) returns the native client namespace; generated wrapper registers it under packageName. Core editor imports no audio. Combined/chime wrappers explicitly inject the shared chime adapter; other splits never import its implementation/assets, enabling real payload exclusion.

Use one ConfigForm seam for shared form and page-form adapter. A section binding projects root value/base/user at ['modules',moduleId], preserves status/writable/root revision, prefixes set/unset paths, and never writes stale entire roots. Canonical envelope is shared across combined and split artifacts. Concurrent section saves conflict safely on root revision; do not auto-rebase dirty drafts. Sidebar rest writes modules.chime.restMode through that same binding. Chime reset unsets only owned fields.

mountChime(ctx,{settings,authority}) returns an idempotent disposer and hides watcher/audio/sidebar/banner details. Requires ready namespace, enabled accepted config, selected module and affirmative migration ownership. Read-only gates editing, not playback. On disable/unserve/ownership loss/unload: hide banner, stop audio, cancel timers, detach optional providers/listeners/slots, clear tracked state and invalidate resume/decode completions. Re-enable starts a silent baseline. Authority must be based on actual migration/host evidence or a fresh-page fence, not settings values alone.

## Safe browser handover

Neither 'row disable always stops audio immediately' nor 'row disable never unloads client' is correct:

1. Legacy chime runtime starts unconditionally; whileServed gates Configure only. Namespace loss sets status unavailable but retains old value, which runtime keeps reading. Sources: [mount](</home/dev/dev/dsh-session-chime/client/main.ts#L1644-L1656>), [Configure gate](</home/dev/dev/dsh-session-chime/client/main.ts#L1910-L1914>), [stale value retained](</home/dev/.local/lib/node_modules/@deepseek-ai/dsh/node_modules/@deepseek-ai/dsh-client-ui-settings/lib/client.js#L1209-L1230>).
2. Host graph skips disabled/fiberless Loader rows and removes package when last source disappears. Browser removes obsolete fibers and waits inertia. Legacy patches normally contain one row, so disabling the sole source can remove browser package. Another active manual source invalidates that assumption. Sources: [host scan](</home/dev/.local/lib/node_modules/@deepseek-ai/dsh/node_modules/@deepseek-ai/dsh-client-modules/lib/index.js#L908-L954>), [browser reconcile](</home/dev/.local/lib/node_modules/@deepseek-ai/dsh/node_modules/@deepseek-ai/dsh-client-modules/lib/client.js#L506-L537>), [single chime row](</home/dev/dev/dsh-session-chime/cordis.patch.yml#L7-L9>).
3. Existing chime has no watcher dispose, raw settle timers, and audio awaits resume/decode before assigning stopCurrent. Those old callbacks can outlive fiber cleanup. New-only ownership locks cannot cancel them. Sources: [watcher return](</home/dev/dev/dsh-session-chime/client/main.ts#L696>), [raw timer](</home/dev/dev/dsh-session-chime/client/main.ts#L1711-L1716>), [forget cleanup](</home/dev/dev/dsh-session-chime/client/main.ts#L596-L602>), [async audio](</home/dev/dev/dsh-session-chime/client/main.ts#L833-L904>), [unload cleanup](</home/dev/dev/dsh-session-chime/client/main.ts#L1771-L1777>).

First release: import with new chime inactive, disable verified old package selection/manual sources, verify host removal, report reload-required, and activate after normal page reload with old package absent. Refresh alone does not fix a still-active source. Each stale tab needs independent fencing/reload. Do not transfer transient playback/question/busy state. Seamless no-reload migration would require a separate tested legacy compatibility/disposal protocol.

## Tests and release gates

Read-only baseline executed successfully: chime 47/47 browser tests plus shape/sound-consistency/freshness checks; retry 16/16 browser tests; context 5/5 browser tests. No build, install, native host launch or real-browser/audio run was performed. VM/stub tests are not installed-profile or actual audio evidence. Sources: [chime tests](</home/dev/dev/dsh-session-chime/test/client.test.ts#L51-L89>), [retry tests](</home/dev/dev/dsh-stream-retry/test/client.test.ts#L56-L126>), [context tests](</home/dev/dev/dsh-tool-compact-context/test/client.test.js#L8-L39>).

Required gates:

- Same module regression contract against combined and split, six sound hashes, all 18 chime fields, false/zero/empty preservation and owned reset.
- Disable/unserve/unload during debounce/resume/decode/repeat/save; no late sound/banner, listener/watch leaks or stale completion clearing newer ring. Re-enable/HMR/service replacement leaves exactly one runtime/slot set.
- Native page form and package fallback, summary without form, read-only/unavailable, sibling-section root-revision conflicts, rest versus dirty draft, no write-after-unmount. Actual rendered switch/preview/seven placements/modal tests.
- Inspect actual tarballs and load emitted entries through native-compatible loader: five unique factories, exact slot keys/exports/patches, no Node imports/second React/global collisions/old ids, no chime code/assets in non-chime splits. Reproducible build rather than mtime-only freshness.
- Disposable real 0.2.2-alpha.3 host and browser only: temporary HOME/DSH_HOME/profile/port, never current GUI. Single combined card/four sections, each split standalone, independent off means no hooks/audio, graph removal and stale-tab/multiple-row/two-tab migration, before/after fresh-page fence. Another module keeping combined browser alive must not keep disabled chime alive.

Implementation-time gaps: exact migration authority metadata projection and browser automation availability need confirmation; passing existing unit baselines does not satisfy these gates.
