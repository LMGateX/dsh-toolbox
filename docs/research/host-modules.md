Root orchestration selects enabled modules and supplies detached/live settings; it must not acquire the union of all feature dependencies and make unrelated modules unavailable. Combined/split orchestration and migration remain outside feature code.

[disposal and stream loop](</home/dev/dev/dsh-stream-retry/src/index.ts#L65-L84>), [captured-stream regression](</home/dev/dev/dsh-stream-retry/test/plugin.test.ts#L247-L265>).
